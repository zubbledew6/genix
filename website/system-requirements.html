System Requirements

Genix is designed to run locally on your machine. The requirements below describe the recommended environment for running Genix and its associated tools.

Operating System

Genix is designed for Gentoo Linux.

Architecture

Genix is intended for x86_64 / AMD64 systems.

Internet Connection

An Internet connection may be required when downloading packages, dependencies, updates, or other resources.

Downloads are handled through the Gentoo mirrors configured on your system. Genix does not require a connection to a Genix cloud service.

Storage

You need sufficient available storage for Genix, its dependencies, temporary build files, and any content generated by the tools.

The amount of storage required can vary depending on what you build or generate.

Memory

Memory requirements depend on the operation being performed and the software or content being generated.

Systems with more available memory may provide a better experience when performing larger or more demanding tasks.

CPU

A 64-bit processor capable of running AMD64 / x86_64 software is required.

CPU requirements may vary depending on the workload. More demanding builds and operations may benefit from additional processing power.

Gentoo Environment

Genix expects a functioning Gentoo Linux environment with the required package-management tools available.

Your Gentoo system should have properly configured package repositories and mirrors.

Dependencies

Some Genix functionality may require additional packages or dependencies.

Dependency requirements may vary depending on the Genix component or operation being used.

Permissions

Certain operations may require elevated permissions depending on what Genix is installing, modifying, rebuilding, or configuring on the system.

Local Storage & Configuration

Genix is designed to keep its configuration and generated content on your local machine.

No Genix account or Genix cloud storage is required.

Quick Requirements

  • Gentoo Linux
  • x86_64 / AMD64 processor
  • Working Gentoo package-management environment
  • Configured Gentoo mirrors
  • Sufficient available storage
  • Sufficient system memory for the workload
  • Internet access when downloads are required

Need Help?

If you are having trouble getting Genix running, check the documentation and FAQ.

You can also report bugs or request help through the Genix GitHub repository .
